# Global Drive Clock V2.8

V2.8 adds a Global / Germany switch while preserving the global model and session clock. Germany mode uses official KBA FZ 27 passenger-car fleet snapshots, with the latest stock as its base and the observed July-to-July change spread evenly over 365 days. The Germany methodology, current reference values, source links, and German-market labels are included. The V2.7 lightning-bolt browser icon, 10 languages, sharing preview, and copyright notice are retained. Asset cache-busting is updated to `?v=2.8`.

The Germany model is an interpolation between official quarterly snapshots, not a live feed of registrations. It uses 1 July 2026 counts and the change from 1 July 2025 to 1 July 2026. “Hybrid total” includes plug-in hybrids; gas and other vehicles are included in the residual category.
